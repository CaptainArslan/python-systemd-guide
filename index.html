ubuntu server guide

Deploy Python on Ubuntu

Every command to install, wire up, and run a Python application as a background service on Ubuntu — using a virtual environment and systemd, in the order you'll actually run them.

Everywhere you see myapp or /var/www/myapp, swap in your own app name and path.

journalctl -u myapp -f

01

Install Python

shell
sudo apt update
sudo apt install -y python3 python3-pip python3-venv

# verify
python3 --version
pip3 --version
02

Go to the project & check layout

shell
cd /var/www/myapp
ls -la

Expected layout:

tree
/var/www/myapp/
├── src/
├── requirements.txt
├── venv/
└── ...
03

Create & use the virtual environment

shell
python3 -m venv venv
ls -la venv/bin/python          # verify

source venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
pip list                       # check installed packages
deactivate
04

Test the application manually

shell
cd /var/www/myapp
venv/bin/python src/main.py
05

Create the systemd service

shell
sudo nano /etc/systemd/system/myapp.service
myapp.service
[Unit]
Description=Python Application Service
After=network.target

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/var/www/myapp
ExecStart=/var/www/myapp/venv/bin/python /var/www/myapp/src/main.py
Restart=always
RestartSec=5
Environment="PYTHONUNBUFFERED=1"

[Install]
WantedBy=multi-user.target

Save in nano: Ctrl + O → Enter → Ctrl + X

06

Set project permissions

shell
sudo chown -R www-data:www-data /var/www/myapp
sudo chmod -R u+rwX /var/www/myapp
07

Reload, enable & start

shell
sudo systemctl daemon-reload
sudo systemctl enable myapp
sudo systemctl start myapp
08

Verify status & read logs

shell
sudo systemctl status myapp

# confirm it's enabled on boot — expect "enabled"
systemctl is-enabled myapp

# last 100 log lines
sudo journalctl -u myapp -n 100 --no-pager

# follow logs live
sudo journalctl -u myapp -f

systemctl cheatsheet

shell
sudo systemctl start myapp
sudo systemctl stop myapp
sudo systemctl restart myapp
sudo systemctl daemon-reload
sudo systemctl enable myapp
sudo systemctl disable myapp
sudo systemctl status myapp

# show the unit file contents
systemctl cat myapp

# show the exact command systemd executes
systemctl show myapp -p ExecStart

.gitignore & keeping venv out of git

.gitignore
venv/
.venv/
__pycache__/
*.pyc
.env

If venv was already committed, untrack it first:

shell
git status
git rm -r --cached venv
git add .gitignore
git commit -m "Ignore Python virtual environment"
git push

Routine deploy (after a pull)

shell
cd /var/www/myapp
git pull origin main
venv/bin/python -m pip install -r requirements.txt
sudo systemctl restart myapp
sudo systemctl status myapp
sudo journalctl -u myapp -n 100 --no-pager

Complete initial setup (one script)

Everything from steps 01–08, back to back — edit the service file line manually when the nano editor opens.

shell
sudo apt update
sudo apt install -y python3 python3-pip python3-venv

cd /var/www/myapp
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
deactivate

venv/bin/python src/main.py    # manual smoke test, Ctrl+C to stop

sudo nano /etc/systemd/system/myapp.service
# paste the unit file from step 05, save & exit

sudo chown -R www-data:www-data /var/www/myapp
sudo systemctl daemon-reload
sudo systemctl enable myapp
sudo systemctl start myapp
sudo systemctl status myapp
sudo journalctl -u myapp -n 100 --no-pager
